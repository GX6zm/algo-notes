# 算法笔记 · 点分治（Centroid Decomposition）

一份讲给"看代码看不懂、看题解更晕"的人看的点分治材料：**8 页图文讲义 + 一个可单步播放的交互动画**，用同一棵 13 个点的带权树贯穿始终，图和动画里的每个数字都对得上。

> 一句话说清点分治：每轮挑出树的重心当"关卡"，只统计跨过这道关卡的路径；没跨过去的路径一定整条躲在某棵子树里，删掉重心后对每块递归。

## 讲义内容

1. **封面导读** —— 一句话概括 + 学习路线
2. **从一道题说起** —— 统计距离 ≤ K 的点对，为什么暴力 O(n²) 不行
3. **树的重心** —— 定义、`maxPart ≤ n/2` 的性质、一次 DFS 求法
4. **三步走流程** —— 找重心 → 统计 → 递归，以及"为什么不重不漏"
5. **Calc 细节** —— 分组收集距离、排序双指针、容斥减掉同组重复
6. **C++ 模板** —— 可直接编译的核心代码，三个 ★ 标注易错处
7. **复杂度与坑** —— O(n log² n) 推导、六个高频错误、题型变形
8. **一页纸速查** —— 口诀、流程表、自测三问（附答案）

## 核心要点速记

```
找重心：maxPart(u) = max( max sz[v], all − sz[u] )   取最小
统计：  Calc(c) = count({0} ∪ 各组距离) − Σ count(每组)
递归：  dead[c] = true，对每个剩余连通块重新找重心
复杂度：每层 O(n log n)，共 O(log n) 层 → O(n log² n)
```
